# YEONGDEUNGPO BIKE FITTING LAB — Beta 1.6.0

Field-oriented saddle-height fitting web app.

## Beta 1.6.0
- Analog Measurement mode: enter height + tape-measured inseam and skip camera/gallery.
- Quick Fitting mode: choose bike type and skip BB floor height/current saddle inputs.
- Quick Measurement result badge and dedicated quick target output.
- Existing camera/gallery, three-point measurement, mechanic dashboard, symptom check, iOS home-screen/PWA support retained.

Calculation baseline: inseam × 0.883, BB center → saddle top, optional crank-length correction.
