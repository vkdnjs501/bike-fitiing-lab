# 자전거 피팅기 (BIKE FITTING LAB)

카메라로 3점(정수리 → 가랑이 → 발끝)을 터치해 **인심(다리 안쪽 길이)** 을 측정하고,
라이딩 자세(세운 자세 / 살짝 숙인 자세 / 매우 숙인 자세)별로 **지면 기준 추천 안장 높이(mm)** 를
계산해주는 순수 HTML/CSS/JS 웹앱입니다. 별도 서버·빌드 과정 없이 정적 파일만으로 동작합니다.

## 파일 구성

```
index.html   메인 마크업
style.css    다크 · 형광 오렌지 톤앤매너 스타일
app.js       카메라 제어, 3점 측정, 계산 로직
```

## GitHub Pages 배포 방법

1. GitHub에 새 저장소를 만듭니다 (예: `bike-fitting-lab`).
2. 이 zip 파일의 압축을 풀고, `index.html`, `style.css`, `app.js` 세 파일을 저장소 **루트**에 그대로 업로드합니다.
   (하위 폴더 없이 루트에 있어야 `https://아이디.github.io/저장소명/` 로 바로 접속됩니다.)
3. 저장소 **Settings → Pages** 에서 Source를 `main` 브랜치 / `root` 로 지정 후 저장합니다.
4. 몇 분 후 `https://아이디.github.io/저장소명/` 주소로 접속하면 바로 실행됩니다.

> 카메라 기능은 **HTTPS** 환경에서만 동작합니다. GitHub Pages는 기본적으로 HTTPS를 제공하므로
> 별도 설정 없이 카메라가 정상 동작합니다. (단, 로컬 `file://` 경로로 열면 카메라가 켜지지 않습니다 —
> 테스트 시에는 `python3 -m http.server` 등으로 로컬 서버를 띄우거나 GitHub Pages 배포본으로 확인하세요.)

## 사용 방법

1. **01 MEASURE** — 신장(cm)을 입력합니다. (사진의 픽셀 거리를 실제 mm로 환산하는 축척 기준입니다.)
2. 카메라를 켜고, 신발을 벗고 벽에 등을 붙인 전신 사진을 촬영합니다.
3. 촬영된 사진 위에서 **① 정수리 → ② 가랑이 → ③ 발끝** 순서로 3번 터치합니다.
   - 3점이 모두 찍히면 자동으로 인심(다리 길이)이 계산됩니다.
   - 카메라 없이 줄자로 잰 인심 길이를 알고 있다면 "직접 입력" 모드로 바로 넣어도 됩니다.
4. **02 SETUP** — 보유 자전거의 바텀브라켓(BB) 높이를 입력하거나 프리셋을 선택합니다.
5. **03 RESULT** — 세 가지 라이딩 자세별 추천 안장 높이(지면 기준, mm)가 동시에 표시됩니다.

## 계산 원리

- 인심(mm) = (가랑이–발끝 픽셀 거리) ÷ (정수리–발끝 픽셀 거리 ÷ (신장cm × 10))
- 추천 안장 높이(mm) = 인심(mm) × 자세 계수 + BB 높이(mm)

| 라이딩 자세 | 계수 | 설명 |
|---|---|---|
| 세운 자세 (Upright) | 0.860 | 시티/하이브리드 등 무릎을 더 굽히는 편안한 자세 |
| 살짝 숙인 자세 (Endurance) | 0.883 | 표준 로드 엔듀런스 자세 — LeMond 공식 기준값 |
| 매우 숙인 자세 (Aggressive) | 0.900 | 에어로/레이싱 포지션 — 힙 드랍 보정 반영 |

이 계수들은 LeMond·Hamley(109%) 계열 공식에서 통용되는 근사 범위를 자세별로 조정한 값이며,
크랭크 길이·클릿 위치·골반 유연성에 따라 개인차가 있으므로 **±5mm 범위의 미세 조정**을 권장합니다.
정밀한 피팅이 필요하다면 전문 피팅샵 방문을 대체하지 않는 참고 도구로 사용해주세요.

## 기술 노트 / 향후 개선 아이디어

- 현재 버전은 **수동 3점 터치 + 신장 기준 축척 보정** 방식으로, 별도 ML 모델 다운로드 없이
  모든 iOS Safari(아이패드/아이폰)에서 안정적으로 동작하도록 설계했습니다.
- 추후 MediaPipe Pose Landmarker 등 카메라 기반 자동 관절 인식 라이브러리를 CDN으로 추가하면
  터치 없이 자동으로 관절 포인트를 추적하는 방식으로 고도화할 수 있습니다. (다만 기기별 성능 편차,
  모델 로딩 시간, 조명 조건에 따른 인식 오차가 있어 우선 수동 방식으로 신뢰도를 확보했습니다.)
- 로컬에서 테스트하려면: `cd bike-fitting-lab && python3 -m http.server 8000` 후
  `http://localhost:8000` 접속 (localhost는 예외적으로 HTTPS 없이도 카메라 허용됨).

## 브라우저/기기 지원

- iPadOS 13인치 Safari, iOS 17 Pro Safari 기준으로 반응형 레이아웃 및 안전 영역(safe-area) 처리를 적용했습니다.
- 카메라 API(getUserMedia) 미지원 브라우저에서는 자동으로 "직접 입력" 안내 문구가 표시됩니다.
